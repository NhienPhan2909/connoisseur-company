# Connoisseur Companion

An AI-powered restaurant recommendation chatbot for California dining, built with
Gradio, an MCP (Model Context Protocol) tool server, and Google Gemini.

Ask about restaurants by name, cuisine, or vibe — e.g. "Find me a moody spot in DTLA"
or "Tell me about Sakura Garden".
